## OakMate version <script>document.write(OakMate.version)</script>

OakMate is a native text editor for macOS. It continues [TextMate 2](https://github.com/textmate/textmate) by MacroMates, whose source code is released under the GNU General Public License, and is named after the Oak frameworks that TextMate is built from.

OakMate reads TextMate bundles, themes, and `.tm_properties` files. The [TextMate manual](https://macromates.com/textmate/manual/), [FAQ](https://github.com/textmate/textmate/wiki/FAQ), and [hidden settings](https://github.com/textmate/textmate/wiki/Hidden-Settings) page mostly apply to OakMate too.

Source code, releases, and issues: <https://github.com/OakMate/OakMate>
